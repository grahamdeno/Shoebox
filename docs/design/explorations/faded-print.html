Faded Print

Color photos kept in a shoebox fade the same way. The cyan dye breaks down first, so the print drifts toward magenta and peach: shadows go plum, skies and skin go peach and rose, the white border warms to cream. This palette is that drift. Every color in Shoebox is something an old snapshot turns into.
